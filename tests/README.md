# Bayside Outfitters FAQ Assistant

This project is a simple FAQ assistant for a fictional outdoor clothing store called Bayside Outfitters. It answers common questions about store hours, returns, shipping, and products. The assistant is a mock chatbot because it uses keyword matching and preset answers instead of a real AI model or live store database. Questions it cannot answer are sent to a human employee so customers can get help instead of receiving incorrect information. If this system used real customer data, private information could be exposed or stored incorrectly without proper security.

## How to Run

Run the chatbot:

python3 my_main.py

Run the tests:

pytest -v
